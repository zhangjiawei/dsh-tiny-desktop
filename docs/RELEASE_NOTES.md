v0.2.0 公开预览版：全新控制中心、首次安装即最新版插件。

- 可选“最小化/关闭后仅驻留托盘”，点击托盘恢复工作空间；恢复不再重新加载当前对话。
- 默认跟随系统语言，可即时切换简体中文 / English；其他系统语言回退 English。仅切换外壳，不改动 DSH 上游界面。
- 修复切换页面后概览按钮及状态刷新被来源检查误拒绝的问题，保留本地控制页与主框架的权限边界。
- 修复 macOS 托盘点击调用 Dock API 时的主线程同步派发崩溃。
- 新增启动命令、HTTPS registry、启动超时与“应用并重启”，提供私有 pnpm dlx 示例。端口、监听和认证仍由外壳管理。
- 六个预置插件在首次运行安装时自动获取最新版，无需设置。精确版本保存到安装回执，普通重启保持已有版本，不静默升级。
- 控制中心重新设计：白色/浅灰底、绿色强调色、紧凑导航、分组设置、多行启动命令输入；中英文布局适配最小窗口尺寸。
- CI 新增真实 pnpm dlx 启动及其原生 PTY 验证，覆盖六种平台/架构。

保留 v0.1.0 能力：

- 自动准备 Node 24 / pnpm / DSH 与六个预置插件。
- 3080 端口冲突回退、认证就绪检查、按进程树退出。
- 控制中心、脱敏日志、浏览器打开、认证链接复制/二维码。
- 独立数据空间、导入预览、可选凭据复制、备份恢复。
- 原创图标、托盘、刷新/缩放/置顶；不包含分屏。

下载前请阅读 README 与 docs/VALIDATION.md。macOS 为 ad-hoc 签名而非 Apple 公证；Windows 未商业签名。Linux 需要 GTK4/WebKitGTK 6.0。认证链接默认仅用于本机且包含完整权限，不要公开；可显式开启可信私有局域网分享，但 HTTP 未加密，系统权限或防火墙可能阻止访问。第三方插件的模型调用、IM 平台绑定、通知能力仍需用户配置相应凭据与系统权限。

构建产物不包含个人配置、密钥或运行时数据。SHA256SUMS.txt 可校验下载完整性；它不是商业发布者签名。
