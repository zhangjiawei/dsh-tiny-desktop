# 实施计划

## 已确认范围

Wails v3 / Go / TypeScript；公开仓库 zhangjiawei/dsh-tiny-desktop；独立数据目录及导入；无分屏。
现有 Node 兼容时复用，否则私有安装 Node 24；私有 pnpm；预装六个指定插件。
默认端口 3080，冲突自动换端口；捕获官方启动 URL、正常 cookie 认证、可随时复制当前链接。
支持托盘、窗口状态、置顶、透明度（按平台能力）、代理、日志、文件交互、更新和跨平台 Release。

## 工作顺序

- [ ] Wails v3 原生窗口与外部 DSH 页面验证
- [ ] 运行环境下载与校验、固定版本安装、恢复机制
- [ ] DSH 进程所有权、端口竞争、认证及分享
- [ ] 控制面板、原创图标、窗口/托盘与文件交互
- [ ] 独立数据目录、导入预览/备份/恢复、更新
- [ ] 六插件真实装配与冷启动验证
- [ ] 测试/构建 CI、公开仓库、Release

## 安全约束

不修改系统 PATH、不申请 sudo、不修改既有 DshShell、不直接绑定 DSH 到公网、不关闭认证。
主 DSH 窗口与可信的本地控制页分离；外链交给系统浏览器，不能访问特权 Go 操作。
日志默认脱敏；令牌只在内存保存，分享明确提示其不是只读权限。
依赖构建仅对锁定且审核的必要依赖授权。

## 发布门槛

测试通过不等于原生 GUI 验证通过。每个平台注明构建、冷启动、GUI、签名状态。
签名证书不可用时只能提供明确标注的未签名预发布包。
